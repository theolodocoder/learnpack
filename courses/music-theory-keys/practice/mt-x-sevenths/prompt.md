# Build seventh and sus chords

Write each chord in **root position**, lowest note first.

- `cmaj7`: C major 7.
- `dm7`: D minor 7.
- `g7`: G dominant 7.
- `asus4`: A sus4 (three notes).
- `chord_with_gaps_4_3_3`: the name of the seventh chord whose notes are 4, then 3, then 3 half steps apart.

Formulas, in half steps from each note to the next: major 7 = 4 3 4, minor 7 = 3 4 3, dominant 7 = 4 3 3, half-diminished 7 = 3 3 4, sus4 = 5 2.

**Names you can use** for the last one (lowercase; capitals and extra spaces are ignored): `"major 7"`, `"minor 7"`, `"dominant 7"`, `"half-diminished 7"`. Writing "seventh" instead of "7" also counts (for example `"dominant seventh"`).

Any spelling of the right pitch counts.

You don't need to know Python: just type your answers between the brackets or quotes.
