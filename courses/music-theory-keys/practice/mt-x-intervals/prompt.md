# Count and name intervals

Count the half steps between two notes, then name the interval. Always count **upwards** from the first note, and don't count the key you start on.

Fill in:

- `c_to_e_half_steps`: how many half steps from C up to E (a whole number).
- `c_to_e_name`: the name of the interval from C up to E.
- `a_to_c_name`: the name of the interval from A up to C.
- `c_to_g_name`: the name of the interval from C up to G.
- `perfect_fourth_above_d`: the note a perfect fourth above D.

**Names you can use** (write them exactly like this, lowercase): `"minor second"`, `"major second"`, `"minor third"`, `"major third"`, `"perfect fourth"`, `"tritone"`, `"perfect fifth"`, `"minor sixth"`, `"major sixth"`, `"minor seventh"`, `"major seventh"`, `"octave"`. Capital letters and extra spaces are ignored.

For the note, any correct spelling counts.

You don't need to know Python: just type your answers between the brackets or quotes.
