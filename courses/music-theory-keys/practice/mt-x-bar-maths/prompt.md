# Bar maths

Count beats like a drummer. Use these numbers for note values in 4/4, where one beat is a quarter note:

| Note | Value |
|---|---|
| Half note | `2` |
| Quarter note | `1` |
| Eighth note | `0.5` |
| Sixteenth note | `0.25` |

1. `beats`: a list of note values that fills exactly one bar of 4/4 (adds up to 4). Use only the four values above, and use at least three different ones. Many answers are right, for example `[2, 1, 0.5, 0.5]`.
2. `eighth_notes_in_bar_of_6_8`: how many eighth notes fill one bar of 6/8 (a number).
3. `beat_groups_in_12_8`: how many felt beats (groups of three eighths) are in one bar of 12/8 (a number).

You don't need to know Python: just type your answers between the brackets or quotes.
