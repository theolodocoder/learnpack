# Inversions

## Why this matters

If you play every chord in root position, your right hand jumps around the keyboard and the chords sound blocky. Experienced church keyboardists barely seem to move: they pick the version of each chord that's closest to the last one. That's inversions. Producers use them too: the same three notes in a different order can sit above a bass line instead of clashing with it. Inversions also explain slash chords like C/E on a chart.

## Root position

A chord is in **root position** when its root is the lowest note. Everything in the last two lessons was written in root position.

```
C major, root position:   C  E  G       (lowest note: C, the root)
gaps:                      4  3
```

An inversion uses exactly the same notes, but puts a different chord note at the bottom.

## First inversion

Take the root off the bottom and move it up an octave. The third is now the lowest note.

```
Root position:     C  E  G
Move C up:            E  G  C
First inversion:   E  G  C      (lowest note: E, the third)
gaps:              3  5
```

It is still a C major chord. Only the order (the **voicing**) has changed.

```
| C | D | E | F | G | A | B | C |
          X       X           X       C major, first inversion
```

## Second inversion

Do it again: take the new bottom note (E) and move it up an octave. Now the fifth is on the bottom.

```
First inversion:   E  G  C
Move E up:            G  C  E
Second inversion:  G  C  E      (lowest note: G, the fifth)
gaps:              5  4
```

Do it once more and you're back in root position, an octave higher.

> **Try it:** Play C E G, then E G C, then G C E, then C E G an octave up. Keep it smooth. Then do the same with F major (F A C, A C F, C F A) and G major (G B D, B D G, D G B).

## The rule in one line

```
Root position     root on the bottom     C E G
First inversion   third on the bottom    E G C
Second inversion  fifth on the bottom    G C E
```

So to answer "what's the lowest note of G major in second inversion?", work it out: G major is G B D, the fifth is D, so D is on the bottom (D G B).

## Recognising the quality from an inversion

The gaps change when you invert a chord, so you can't use 4 3 or 3 4 directly. Instead, rearrange the notes until they stack in thirds, then measure.

```
Notes on the keys:     A  C  F
Rearrange in thirds:   F  A  C     gaps 4 3 -> F major
So A C F is F major, first inversion.
```

Here are the shapes for a major and a minor triad in all three positions:

```
                  Root pos.   1st inv.   2nd inv.
Major gaps        4 3         3 5        5 4
Minor gaps        3 4         4 5        5 3
```

In both inversions, the gap of 5 (a perfect fourth) has the root on its top end. That's a quick way to spot the root by ear and by sight.

## Seventh chords have three inversions

A four-note chord can have any of its four notes on the bottom.

```
Cmaj7 root position:   C  E  G  B
First inversion:       E  G  B  C     (third on the bottom)
Second inversion:      G  B  C  E     (fifth on the bottom)
Third inversion:       B  C  E  G     (seventh on the bottom)
```

Gospel keyboardists use these a lot to keep a four-note chord under one hand position while the left hand plays the bass.

## Voice leading: why inversions sound smoother

Voice leading means moving from one chord to the next with each finger travelling as little as possible. Compare these two ways of playing C to F to G to C:

```
All root position:         C E G  ->  F A C  ->  G B D  ->  C E G
Big jumps, every finger moves every time.

With inversions:           C E G  ->  C F A  ->  B D G  ->  C E G
                                      (2nd inv.)  (1st inv.)
Common notes stay put, the rest move by a step.
```

From C E G to C F A: the C stays, E moves up to F, G moves up to A. From C F A to B D G: C moves down to B, A moves down to G, and F moves down to D. That's why the second version sounds like a choir rather than a set of block chords.

> **Try it:** Play C, F, G, C both ways above. Then try a four-chord loop you know from church or a song you like, and find the voicing for each chord that's closest to the one before.

## Slash chords

On a chord chart, a slash shows which note goes in the bass:

```
C/E   C major with E in the bass     (first inversion)
C/G   C major with G in the bass     (second inversion)
F/A   F major with A in the bass     (first inversion)
G/B   G major with B in the bass     (first inversion)
```

You'll see these all the time in worship charts, often to make a bass line walk step by step: C, G/B, Am is a common descending line (C, B, A in the bass). A slash can also name a bass note that isn't in the chord at all, like F/G. That isn't an inversion; it's a different sound, and we'll come back to it.

Watch the "Inversions" clip from Andrew Huang's video and the "Chord inversions" clip from Marks Piano, then try the practice. In the exercise, order matters: write the notes from the lowest up.

## Common mistakes

- **Changing the notes, not the order.** An inversion uses exactly the same notes. E G C is C major; E G B is a different chord (E minor).
- **Thinking an inversion changes the chord's name.** E G C is still C major. Only the bass note and the voicing changed.
- **Mixing up first and second.** First inversion has the third on the bottom; second has the fifth. Count "root, third, fifth" and match the lowest note.
- **Judging the quality from the gaps of an inversion.** E G C has gaps 3 and 5, which isn't a minor triad. Rearrange into thirds before naming it.
- **Ignoring the bass player.** If the bass plays the root, your inversion in the right hand sounds like a fuller root-position chord. Inversions in the right hand are about smoothness; the bass note on the chart is what decides the slash chord.

## Recap

- Root position has the root on the bottom; first inversion the third; second inversion the fifth.
- Inverting moves the bottom note up an octave; the chord's name stays the same.
- Major gaps: 4 3, 3 5, 5 4. Minor gaps: 3 4, 4 5, 5 3. The root is at the top of the 5 gap in an inversion.
- Seventh chords have a third inversion, with the seventh on the bottom.
- Choose inversions so common notes stay and the rest move by step.
- Slash chords like C/E name the bass note.
